Developer Documentation

Integration documentation follows the real Compflow execution model. The API is organized around durable scans, findings, evidence, exposure analysis and controlled remediation—not simulated cloud state.

Authentication & tenancy

Authenticate through the configured API authentication flow. Requests operate in an organization/tenant context. Do not treat client-supplied organization identifiers as authority.

Core lifecycle

  1. Connect a supported cloud provider.
  2. Run a provider-backed scan.
  3. Inspect findings and durable evidence.
  4. Analyze exposure paths and deterministic risk.
  5. Create and approve a remediation according to policy.
  6. Execute the authorized cloud operation.
  7. Collect fresh provider evidence.
  8. Re-analyze and verify the security effect.

Important API surfaces

  • /api/scan — scan operations.
  • /api/remediate — remediation workflow.
  • /api/remediation-verification — execution, verification and reanalysis lifecycle.
  • /api/execution-graph — durable execution graph and events.
  • /api/auditor — auditor evidence and verification surfaces.
  • /api/v1 — versioned API surface.

Endpoint behavior must be treated as implementation authority; this page intentionally does not invent request or response schemas that are not established by the service.

Evidence and proof

Evidence is provider-backed and carries lineage. Reanalysis claims require a fresh completed scan and independent evidence. A “Proven” security effect means deterministic analysis found measurable reduction; an AI explanation cannot manufacture that state.

AI analyst

The analyst is an explanation layer. Semantic contract versions such as security-analyst-v7 make explanation behavior reproducible. Models do not override findings, evidence, exposure relationships or remediation proof.

Errors & uncertainty

Clients should handle explicit failure and inconclusive states. A missing observation is not equivalent to a secure observation, and a successful provider API response is not equivalent to verified security state.
