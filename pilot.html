Sign in to your pilot

Your pilot invitation code is your login credential. Use the secure link you received or enter the code manually. The code is tied to the invited company email and remains valid only until the invitation expires or is revoked.

The invitation code is a high-entropy, time-limited credential. Compflow stores only its hash, rate-limits attempts, binds it to the invited email, and allows platform admins to revoke the pilot.
